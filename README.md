# NO BORRAR — cascaron pre-montado de `alquimia-urbana`

Este repo existe para que, el dia de la mudanza, la liga vieja
`https://alexpueblag.github.io/alquimia-urbana/` no muera ni un minuto.

Ese dia se renombra a `alquimia-urbana` y toma su lugar **ya construido**.
Mientras tanto no sirve a nadie y parece basura. No lo es.

Borrarlo obliga a crear el cascaron a mano el dia del corte, con la
liga vieja caida mientras tanto — y con el riesgo de que GitHub haya
retirado el nombre `alquimia-urbana` por trafico, en cuyo caso esa direccion
se pierde para siempre.
